# ООО «Обувь» — информационная система учёта заказов

Приложение на C# (WPF, .NET 10), база — MySQL 8.0. Готовый дамп с данными лежит в `db/dump/shoe_store.sql`.

## Что сделано

1. По Excel-файлам спроектирована база: 12 таблиц, справочники, связи 1:N и N:M.
2. Пользователи перенесены в MySQL. После входа главный экран показывает ФИО, логин, роль и отдел, есть поиск по ФИО.
3. Вход по логину и паролю из задания 1. Первое окно при запуске — окно входа, есть режим гостя.
4. Роли и отделы вынесены в отдельные таблицы. По ним работают фильтры в таблице пользователей.

## Требования

- Windows 10 или 11;
- Visual Studio с рабочей нагрузкой «Разработка классических приложений .NET» (проверено на Visual Studio Community 2026);
- .NET SDK 10.0;
- MySQL Server 8.0 и MySQL Workbench.

## Запуск базы

Дамп создаёт схему `shoe_store`, таблицы и загружает данные. Другие схемы на сервере он не трогает.

1. Откройте MySQL Workbench и подключитесь к `localhost:3306`.
2. `File → Open SQL Script…`, выберите `db/dump/shoe_store.sql`.
3. Нажмите кнопку выполнения (жёлтая молния). Дождитесь окончания скрипта.
4. Нажмите «Обновить» в панели Schemas — появится `shoe_store`.

Проверка в новом окне запроса:

```sql
USE shoe_store;

SELECT COUNT(*) FROM users;        -- 10
SELECT COUNT(*) FROM products;     -- 30
SELECT COUNT(*) FROM pickup_points;-- 36
SELECT COUNT(*) FROM orders;       -- 10
SELECT COUNT(*) FROM order_items;  -- 20
SELECT SUM(total_amount) FROM orders; -- 290337.56
```

Приложение подключается к базе под `root` с паролем `root` (локальный стенд). Если пароль другой, поправьте строку подключения в `src/ShoeStore.App/appsettings.json`:

```
"Server=127.0.0.1;Port=3306;Database=shoe_store;User ID=root;Password=ВАШ_ПАРОЛЬ;Character Set=utf8mb4;Connection Timeout=5;"
```

Файл копируется в папку сборки, поэтому после правки выполните пересборку.

## Запуск приложения

1. Откройте `ShoeStore.sln` в Visual Studio.
2. В обозревателе решений проверьте, что запускаемым назначен `ShoeStore.App` (правой кнопкой по проекту → «Назначить запускаемым проектом»). Остальные проекты — библиотека и тесты.
3. Нажмите F5.

Откроется окно входа. Можно войти под одной из учётных записей или нажать «Продолжить как гость».

Если вместо окна появилось сообщение об ошибке подключения, проверьте, что служба MySQL запущена и строка подключения совпадает с вашим паролем.

## Тесты

Автотесты находятся в `tests/ShoeStore.Tests` (xUnit). Без переменной окружения запускаются только модульные проверки, тесты на реальной базе пропускают работу.

```powershell
dotnet test ShoeStore.sln
```

Проверка с базой:

```powershell
$env:SHOE_STORE_TEST_CONNECTION="Server=127.0.0.1;Port=3306;Database=shoe_store;User ID=root;Password=root;Character Set=utf8mb4;Connection Timeout=5;"
dotnet test ShoeStore.sln
```

Всего 28 тестов: 21 модульный и 7 интеграционных. Интеграционные тесты создают временный товар и заказ, проверяют их и удаляют за собой.

## Примечания

- В архиве заданий нет изображений товаров, поэтому поле `image_path` в базе пустое. Интерфейс фотографии не отображает.
- Дамп содержит только данные предметной области. Локальные файлы с паролями в репозиторий не добавлялись.
- Все SQL-запросы параметризованы, направление сортировки выбирается из белого списка.
