## 2. Автотесты

| Файл | Проверок | Что проверяется |
|---|---:|---|
| `SkuTests.cs` | 7 | Нормализация артикула, замена кириллических омоглифов, отказ при недопустимых символах |
| `SqlHelpersTests.cs` | 8 | Экранирование `%`, `_`, `\` для `LIKE`; округление денег; расчёт цены со скидкой |
| `RolePermissionsTests.cs` | 4 | Матрица прав для администратора, менеджера, клиента и гостя |
| `AuthHashTests.cs` | 2 | bcrypt-хеш администратора: верный пароль проходит, неверный — нет |
| `RealDatabaseTests.cs` | 7 | Реальная база: количества, вход, SQL-инъекция, поиск и фильтры, CRUD товара и заказа |

Команда:

```powershell
dotnet test ShoeStore.sln
```

Интеграционные тесты включаются переменной окружения:

```powershell
$env:SHOE_STORE_TEST_CONNECTION="Server=127.0.0.1;Port=3306;Database=shoe_store;User ID=root;Password=root;Character Set=utf8mb4;Connection Timeout=5;"
dotnet test ShoeStore.sln
```

Без переменной тесты `RealDatabaseTests` завершаются без обращения к базе. С переменной они создают временный товар и заказ, проверяют их и удаляют; контрольные количества после прогона не меняются.

## 4. Найденные дефекты

| № | Дефект | Причина | Исправление | Статус |
|---:|---|---|---|---|
| 1 | Гость видел пустую таблицу пользователей под заголовком «Товары» | Скрытая вкладка «Пользователи» оставалась выбранной | При отсутствии пользователя выбирается вкладка «Товары» | Исправлен, проверен |
| 2 | Артикул с дефисом отклонялся | Правило допускает только латинские буквы и цифры | Сообщение уточнено, проверка оставлена по модели данных | Не дефект |
| 3 | `.slnx` не открывался в старых версиях Visual Studio | Формат решения `.slnx` | Решение пересоздано как классический `ShoeStore.sln` | Исправлен |

## 5. Безопасность

| Проверка | Результат |
|---|---|
| Пароли в БД | bcrypt, cost 12; открытого текста в дампе нет |
| SQL-инъекции | Все запросы параметризованы; попытка входа и поиска с `OR 1=1 --` покрыта тестом |

| Секреты в репозитории | Локальные файлы паролей не добавлены; в дампе только предметные данные |
| Состояние после восстановления | Служебных сессий и временных записей нет |

## 7. Ограничения проверки

- Автоматизации WPF-интерфейса нет; сценарии раздела 3 выполнены вручную.
- Интеграционные тесты работают с базой `shoe_store` и удаляют созданные записи. Для постоянной проверки лучше использовать отдельную копию базы.
- Конкурентная работа нескольких пользователей не проверялась.
